Magik Blocks TW

Instalación:
1. Abre Pinegrow
2. Manage Libraries & Plugins
3. Add Library
4. Selecciona magik-blocks-tw.zip

Requisitos:
- Proyecto con Tailwind CSS activo (la librería hereda el CSS del proyecto)

Dark mode:
- Añade class="dark" al <html> o <body> para activar variantes dark

Notas:
- Los bloques usan presets cerrados (color/size/featured/layout)
- El botón ghost es solo para fondos oscuros
- Mantén los atributos data-pg-* y data-magik-block en el nodo raíz
