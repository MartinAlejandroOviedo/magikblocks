Ayuda rápida

Cómo usar Magik Blocks TW

Bloques Tailwind listos para Pinegrow. Requieren que tu proyecto ya tenga Tailwind activo (el CDN del archivo sirve solo para la vista previa de la librería).

Abrir librería Volver al catálogo

1. Publicar en GitHub Pages

  1. Copia todo el contenido de la carpeta en un repo nuevo.
  2. Commit, push y activa GitHub Pages con fuente main y carpeta /.
  3. Comprueba que responde https://<usuario>.github.io/<repo>/magik-blocks-tw.html.

2. Cargar la librería en Pinegrow

  1. Asegúrate de que tu proyecto ya compila Tailwind.
  2. En Pinegrow: Manage Libraries & Plugins → Add Library → Remote file (URL).
  3. Pega la URL pública de magik-blocks-tw.html (ej: https://<usuario>.github.io/<repo>/magik-blocks-tw.html).
  4. Los bloques aparecerán en el panel y podrás arrastrarlos al canvas.

3. Prueba local rápida (sin Pages)

  1. Desde esta carpeta, levanta un server: python -m http.server 8080.
  2. En Pinegrow usa http://localhost:8080/magik-blocks-tw.html como URL de librería.

Notas y tips

  • El CSS proviene de tu proyecto Tailwind; el CDN del archivo solo ayuda a ver la librería.
  • El bloque raíz de cada componente usa pg-lib-item y los campos editables llevan data-pg-edit.
  • Para activar variantes dark, agrega class="dark" en <html> o <body> de tu proyecto.
