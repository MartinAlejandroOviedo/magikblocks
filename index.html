Pasos rápidos

  1. Copia todos los archivos de esta carpeta al repo que uses para Pages.
  2. Commit y push; activa GitHub Pages con fuente `main` (carpeta `/`).
  3. En Pinegrow: Manage Libraries & Plugins → Add Library → Remote file (URL) → pega la URL de librería.
  4. Verifica que los bloques aparecen y se arrastran en un proyecto con Tailwind activo.

Nota: `magik-blocks-tw.html` no incluye Tailwind; reutiliza el Tailwind de tu proyecto.
